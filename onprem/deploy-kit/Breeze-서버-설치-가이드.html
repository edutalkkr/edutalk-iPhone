0준비물을 확인해요

아래 네 가지만 있으면 돼요.

🖥 서버 PC

Windows 10/11, 메모리 4GB 이상. 가능하면 유선 랜으로 연결하고, 꺼지지 않게 상시 전원을 사용해요.

📦 브리즈 서버 폴더

BreezeServer 폴더 전체(압축을 푼 상태)를 준비해요. 안에 breeze-server.exe가 들어 있어요.

🌐 같은 교내망

선생님 PC와 학생 크롬북이 서버 PC와 같은 공유기·같은 내부망에 있어야 해요.

👤 관리자 권한

서버 PC의 Windows 관리자 계정이 필요해요. 설치 파일을 우클릭 → 관리자 권한으로 실행해요.

💡 인터넷이 꼭 필요한가요?아니요. 브리즈는 교내망만으로 동작해요. 인터넷은 나이스 연동·AI 상담을 쓸 때만 있으면 되고, 없어도 서버는 정상 동작해요.

1서버 폴더를 놓아요

서버 PC의 C:\Breeze 폴더에 압축을 풀어 주세요.

  1. 폴더 만들기 — 탐색기에서 C:\로 이동해 Breeze 폴더를 만들어요.
  2. 압축 풀기 — 받은 BreezeServer-win-x64.zip을 그 폴더에 풀어요. breeze-server.exe, 설치 파일, 이 가이드가 한 폴더에 모여야 해요.
  3. 경로 확인 — 최종 경로가 C:\Breeze\breeze-server.exe인지 확인해요. 경로에 한글이 없으면 가장 안전해요.
⚠ 한글·공백이 있는 경로는 피해 주세요C:\사용자\홍길동\바탕 화면 같은 경로는 권한·인코딩 문제가 생길 수 있어요. C:\Breeze를 권장해요.
💡 SmartScreen 경고가 뜨면서명 비용 문제로 아직 전자 서명이 없어요. 파란 경고창이 보이면 [추가 정보] → [실행]을 눌러 주세요. 학교 보안 프로그램이 차단하면 IT 담당자에게 breeze-server.exe 예외 등록을 요청해 주세요.

2서버를 설치해요 자동 시작

설치 파일 하나로 부팅 시 자동 시작과 방화벽 허용이 한 번에 끝나요.

  1. 설치 파일 실행 — install-server.bat을 우클릭 → 관리자 권한으로 실행해요.
  2. 자동 처리 확인 — 아래 세 가지가 자동으로 돼요.

    ✅ 부팅 시 자동 시작

    Windows 예약 작업으로 등록돼요. 로그인하지 않아도 서버가 켜져요.

    ✅ 방화벽 허용

    TCP 3000 포트와 서버 프로그램의 인바운드를 열어요.

  3. 관리 페이지 열기 — 설치가 끝나면 브라우저가 http://localhost:3000/admin을 자동으로 열어요.
서버 PC에서 여는 관리 페이지
http://localhost:3000/admin
🌐
⚠ 반드시 서버 PC에서 여세요초기 설정(관리자 계정·이용권)은 서버 PC 본체에서만 할 수 있어요. 다른 PC에서는 보안을 위해 막혀 있어요.

관리 페이지에 들어가면 1·2단계 마법사가 보여요.

✅완료채팅·쪽지 열림
  1. 관리자 계정 — 사번(영문·숫자 3~20자), 이름, 비밀번호(4자 이상)를 입력해요. 이 계정이 학교의 최고 관리자가 돼요.
  2. 이용권 — 이용권 키가 있으면 입력하고, 없으면 [30일 무료 체험 시작]을 눌러요. 체험 중에도 모든 기능을 쓸 수 있어요.
  3. 자동 로그인 토큰 — 설정을 마치면 관리 페이지가 토큰을 자동으로 채워요. 서버 PC에서는 따로 입력할 필요가 없어요.
✓ 이제 채팅이 열렸어요설정 완료 전에는 로그인·쪽지·실시간 알림이 모두 잠겨 있어요. 마법사를 마치면 바로 풀려요.

4학교 코드와 명단을 등록해요

학교 코드는 학생이 로그인할 때 쓰는 우리 학교의 고유 코드예요.

① 학교 코드 정하기

  1. 관리 페이지의 [🏫 학교 코드 · 학생 웹 연결] 카드로 가요.
  2. 학교 이름과 학교 코드를 입력해요. 예: 가락고 / GARAK
  3. [저장]을 누르면 학생 웹 로그인 화면에 코드가 안내돼요.

② 계정 명단 올리기

  1. 계정_명단_양식.xlsx를 열어 선생님·학생 명단을 채워요.
  2. 관리 페이지의 [엑셀 올리기]에서 파일을 선택해요.
  3. 결과 화면에 나온 임시 비밀번호를 선생님·학생에게 전달해요. 임시 비밀번호는 이 화면을 닫으면 다시 볼 수 없어요.
열 이름설명예시
username사번·학번 (영문·숫자 3~20자)20250101
real_name이름김하늘
password비밀번호 (비우면 임시 비밀번호 자동 발급)(비워도 돼요)
department부서 ( >로 하위 부서 )교무부>1학년부
roleTEACHER·STAFF·STUDENT·ADMINTEACHER
is_paid_dual_network유료 듀얼 사용 여부 (0/1)0
💡 학생 계정은 role을 STUDENT로학생은 /student/ 웹에서만 로그인하고, 선생님에게만 쪽지를 보낼 수 있어요. 관리자·교사 계정과 분리돼요.

5교사 앱과 학생 웹을 연결해요

서버가 켜지면 같은 교내망의 모든 기기에서 접속할 수 있어요.

🖥서버 PCbreeze-server.exe
⇄
📶교내 공유기같은 내부망
⇄
💻선생님 PC브리즈코어 앱
🎒학생 크롬북웹 브라우저

선생님 · 브리즈코어 앱

  1. 선생님 PC에 브리즈코어 앱을 설치해요. (Breeze-setup.exe)
  2. 앱 설정 → 학교 서버 연결에 서버 주소를 입력해요. 예: http://192.168.0.10:3000
  3. 관리자가 만든 교사 계정으로 로그인해요.

학생 · 설치 없는 웹

  1. 크롬북·태블릿 브라우저를 열고 학생 웹 주소로 접속해요. 예: http://192.168.0.10:3000/student/
  2. 학교 코드 + 학번 + 비밀번호로 로그인해요.
교사 앱 서버 주소 · 학생 웹 주소는 설치 파일이 알려 줘요
check-server.bat 으로 언제든 다시 확인할 수 있어요
🔎
⚠ IP 주소가 바뀌면 접속이 안 돼요서버 PC의 IP는 공유기에서 고정 IP(또는 DHCP 예약)로 설정해 두는 걸 권장해요.

✓최종 확인 체크리스트

아래 항목이 모두 체크되면 학교에 공개할 준비가 끝나요.

  • 서버가 자동으로 켜져요 — PC를 재부팅한 뒤 check-server.bat에서 “자동 시작: 등록됨 / 실행 상태: 켜짐”을 확인해요.
  • 관리 페이지가 열려요 — 서버 PC에서 http://localhost:3000/admin에 접속해요.
  • 다른 PC에서도 열려요 — 선생님 PC에서 http://서버IP:3000/admin 접속을 확인해요. (관리 기능은 토큰 필요)
  • 학생 웹이 열려요 — http://서버IP:3000/student/에서 학교 코드가 보이는지 확인해요.
  • 교사 앱 로그인이 돼요 — 서버 주소를 입력하고 교사 계정으로 로그인해요.
  • 쪽지 왕복이 돼요 — 교사끼리 쪽지를 보내고, 학생 → 교사 문의가 “학생 문의” 탭에 도착하는지 확인해요.
  • 백업 폴더가 생겼어요 — C:\Breeze\data\backups가 자동으로 만들어져요. (매일 새벽 3:30)
  • 방화벽·보안 예외 — 학교 보안 프로그램이 서버를 막지 않는지 IT 담당자와 확인해요.

!문제가 생기면

대부분의 문제는 아래 표로 해결돼요.

증상확인해 보세요
브라우저가 “사이트에 연결할 수 없음”으로 떠요① check-server.bat에서 실행 상태가 “켜짐”인지 확인해요. ② 꺼져 있으면 restart-server.bat을 관리자 권한으로 실행해요.
다른 PC에서만 접속이 안 돼요① 서버 PC와 같은 공유기인지 확인해요. ② Windows 방화벽에서 Breeze Server 규칙이 “허용”인지 확인해요. ③ IP가 바뀌지 않았는지 check-server.bat으로 확인해요.
포트 3000을 다른 프로그램이 써요설치 스크립트가 안내해요. 그 프로그램을 끄거나, 서버 PC에서 set EDUTALK_PORT=3001 후 다시 실행해요. (방화벽 규칙도 3001로 다시 등록)
서버가 켜지다가 바로 꺼져요C:\Breeze\logs 폴더의 최신 로그를 열어 원인을 확인해요. 데이터 폴더 권한 문제면 C:\Breeze에서 다시 실행해요.
관리자 토큰을 모르겠어요서버 PC에서 관리 페이지를 열면 자동으로 채워져요. 다른 PC라면 C:\Breeze\data\.admin_token 파일을 메모장으로 열어 값을 복사해요.
Excel 업로드가 실패해요첫 번째 시트에 username·real_name 열이 있는지 확인해요. 최대 5,000명까지 올릴 수 있어요.
“다른 PC의 라이선스예요”가 떠요다른 서버의 license.key가 폴더에 들어 있어요. 그 파일을 지우고 [30일 무료 체험 시작]을 눌러요.
SmartScreen이 실행을 막아요[추가 정보] → [실행]을 눌러요. 학교 보안 프로그램은 IT 담당자에게 예외 등록을 요청해요.

🔒꼭 지켜야 할 보안 수칙

절대 서버 폴더에 두면 안 되는 파일license-vendor-private.key — 이 파일이 있으면 누구나 유효한 이용권을 만들 수 있어요. 오프라인 벤더 PC에만 보관해요.

🔑 license.secret

서버 등록 코드예요. 외부에 노출하지 말고, 노출이 의심되면 새로 발급해요.

🗄 data 폴더

계정·쪽지·백업이 들어 있어요. 서버 PC 밖으로 함부로 복사하지 않아요.

👤 관리자 계정

추측하기 쉬운 비밀번호는 피하고, 관리자 계정은 꼭 필요한 사람만 사용해요.

💾 백업

data\backups의 최근 백업을 주 1회 외장 드라이브에 복사해 두면 안전해요.

?자주 묻는 질문

인터넷이 끊겨도 쓸 수 있나요?

네. 브리즈는 교내망 안에서만 동작해요. 나이스 급식·학사일정과 AI 상담만 인터넷이 필요하고, 없어도 메신저·쪽지·결재·보드는 정상이에요.

서버 PC를 껐다 켜도 설정이 유지되나요?

네. 계정·쪽지·설정은 C:\Breeze\data에 저장돼요. PC를 재부팅하면 자동 시작 작업이 서버를 다시 켜요.

학생은 어떻게 설치하나요?

설치하지 않아요. 크롬북·태블릿 브라우저에서 http://서버IP:3000/student/로 접속하면 돼요.

선생님 앱은 어디서 받나요?

브리즈코어 사이트의 설치 안내에서 Breeze-setup.exe를 받아 설치해요. 설치 후 설정에서 학교 서버 주소를 입력해요.

서버를 다른 PC로 옮기고 싶어요

폴더 전체를 새 PC의 같은 경로에 복사하고 install-server.bat을 다시 실행해요. 데이터가 그대로 따라가요.

이용권은 어떻게 등록하나요?

관리 페이지의 이용권 카드에 키를 붙여 넣고 저장해요. 체험 중에도 언제든 등록할 수 있어요.
