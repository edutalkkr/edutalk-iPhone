브리즈 서버 (Breeze Server) — 학교 내부망 메신저 서버
========================================================

이 폴더는 학교 서버 PC에서 브리즈를 바로 실행할 수 있게 만든 배포 키트예요.


■ 빠른 시작 (3단계)
--------------------------------------------------------
1) 이 폴더 전체를 C:\Breeze 에 복사해요.
2) install-server.bat 을 [우클릭 → 관리자 권한으로 실행]해요.
   → 부팅 시 자동 시작 + 방화벽 허용 + 지금 바로 시작이 한 번에 돼요.
3) 브라우저에서 http://localhost:3000/admin 을 열고
   관리자 계정을 만든 뒤 [30일 무료 체험 시작]을 눌러요.


■ 자세한 설명은 이 파일을 열어 주세요
--------------------------------------------------------
   Breeze-서버-설치-가이드.html
   (브라우저에서 열리며, Ctrl+P 로 인쇄할 수 있어요.)


■ 자주 쓰는 파일
--------------------------------------------------------
   install-server.bat     서버 설치 (자동 시작 등록 + 방화벽 허용)
   restart-server.bat     서버 다시 시작
   check-server.bat       상태 확인 + 접속 주소 보기
   uninstall-server.bat   자동 시작 해제 + 서버 중지
   계정_명단_양식.xlsx     교직원·학생 명단 엑셀 양식
   data\                  계정·쪽지·백업 (자동 생성)
   logs\                  활동 로그 (자동 생성)


■ 접속 주소
--------------------------------------------------------
   관리 페이지 : http://localhost:3000/admin  (서버 PC에서만)
   교사 앱     : http://서버IP:3000
   학생 웹     : http://서버IP:3000/student/


■ 주의
--------------------------------------------------------
   · license-vendor-private.key 파일은 절대 이 폴더에 두지 마세요.
   · license.key 가 다른 서버의 것이면 체험이 시작되지 않아요.
     이 키트에는 license.key 가 들어 있지 않아요. (체험으로 시작)
   · 서버 PC의 IP가 바뀌지 않게 공유기에서 고정 IP(또는 DHCP 예약)를
     설정해 두는 것을 권장해요.
   · 데이터는 C:\Breeze\data 에 있어요. 백업은 data\backups 에 매일
     새벽 3:30 에 자동으로 만들어져요. (최근 14개 보관)
