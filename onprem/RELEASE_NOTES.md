# 브리즈 학내망 서버 v1.0.0

학교 PC 1대에 설치하면 학내망 전용 메신저가 열립니다.

## 받는 파일

- `breeze-server.exe` (Windows 64비트, Node 설치 불필요)

## 설치 (약 10분)

1. exe를 학교 PC에 복사해 더블클릭
2. 방화벽 팝업에서 [액세스 허용]
3. 브라우저에서 `http://localhost:3000/admin` 접속
4. 1단계: 관리자 계정 만들기 → 2단계: 이용권 등록(또는 30일 체험)
5. 엑셀 명단 업로드 → 앱에서 서버 주소 입력 후 연결

자세한 방법은 앱의 **전체 설정 → 네트워크 → 📖 내부망 서버 설치 방법 보기**를 눌러 주세요.

## 주의

- 처음 실행 때 Windows에서 "차단됨"이 뜨면 [추가 정보] → [실행]을 눌러 주세요. (서명 없는 프로그램 공통 안내입니다)
- 서버를 끄면 내부망 방이 안 열립니다. 학교 PC는 항상 켜 두세요.
