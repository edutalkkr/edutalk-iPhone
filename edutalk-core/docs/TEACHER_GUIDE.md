# 브리즈 교사 1장 가이드 — 10월 베타

## 1. 설치 (1분)
1. `Breeze-0.1.0_x64-setup.exe` 실행 → 설치
2. 첫 화면에서 이름·담임(학년/반)·학교ID 입력 → 시작
3. 창은 세로형 400px이 기본. 옆에 띄워두고 쓰세요. 넓게 보고 싶으면 설정 → 창 모양 → 가로형

## 2. 시간표 가져오기 (2분)
1. 시간표 탭 → 📥 CSV 가져오기
2. 나이스 시간표 CSV 그대로 붙여넣기 (요일,교시,학년,반,과목,교실,교사 — 열 이름 달라도 자동 인식)
3. 반영하기 → 오늘 요일 탭에서 확인

## 3. 대강 요청·수락 시연 (1분) — 킬러 기능
1. 시간표 칸 클릭 → 보강 추천에서 교사 선택 → 사유 적고 “보강 요청 보내기”
2. 상대 PC에 쪽지 + 보강 요청이 동시에 도착
3. 상대가 시간표 탭 → 대강·교체 기록 → “수락 (시간표 즉시 반영)”
4. 양쪽 시간표에 ●변경 표시. 거절하면 요청자에게 알림

## 4. 메신저
- 쪽지함: 제목·수신확인·재촉·댓글 있는 정식 쪽지
- 빠른 대화: 가벼운 1:1 대화. 서로 상단 버튼으로 오갈 수 있음
- 주민번호·카드번호·비밀번호는 보내기 전 이 PC에서 차단 + 감사로그 기록

## 5. 연결 상태
- 🔵 교내연결: 같은 교내망 PC끼리 직접. 대강 자동반영·원격지원은 여기에서만
- 🟢 외부연결: 외부망 중계. 대강은 “웹 변경함 주소 복사” → 브라우저에서 승인

## 6. 의견 보내기 (필수)
- 상단 ✋ 의견 버튼 → 불편·오류·추가 희망 기능 작성 → 보내기
- 모은 의견은 보안·감사 탭 → 10월 베타 의견에서 확인
- 이용권: 상단 “🔄 이용권 확인” (학교ID 기준, 소통 전용은 시간표 차단)

## 7. 요금 (10월 베타 기간 전 학교 무료)
- 소통 전용 1년 99,000원 / 기본 1년 198,000원 / 듀얼 1년 297,000원 (부가세 별도)
- 자세한 요금 안내는 웹 첫 화면 → 요금 안내에서 확인

## 문제 해결
- 상대 PC가 안 보임: 둘 다 🔵 교내연결인지 확인 (같은 와이파이/유선망)
- 시간표가 비어 있음: CSV 가져오기 다시 실행 (학년/반 확인)
- 수락했는데 상대에 반영 안 됨: 상대가 교내연결인지 확인 후 ✋ 의견에 기록
