사이트 설정을 관리해요

브리즈 관리자 계정으로 로그인하면 소개 문구와 팝업 내용을 바꿀 수 있어요.

⚠️ 여러 번 연속하여 비밀번호를 틀릴 시 비정상 접근으로 감지되어 IP 주소가 기록될 수 있어요. 관리자가 아니라면 이 페이지를 나가주세요.

이메일은 Firebase Auth에 등록된 관리자 계정(브리즈 앱에서 관리자 역할을 가진 계정)을 사용해요. 비밀번호는 이 브라우저에 저장되지 않아요.

소개 사이트 설정

저장하면 방문자 화면의 문구와 팝업에 바로 반영돼요.

관리자 비밀번호 변경

현재 비밀번호를 확인한 뒤에만 변경할 수 있어요. 관리자 계정으로 로그인된 상태에서만 동작해요.

비정상 접근 기록

3회 이상 비밀번호를 틀린 시도의 IP 주소가 기록돼요. 본인이 틀린 기록이라면 삭제할 수 있어요.

기록이 없어요.

관리자 계정이 아니에요

이 페이지는 브리즈 관리자 역할을 가진 계정만 사용할 수 있어요. 학교 관리자에게 역할을 요청해 주세요.

Firebase 설정이 필요해요

배포할 때 scripts/sync-sites.mjs가 public/firebase-config.js를 이 폴더로 자동 복사해요. 설정이 없으면 사이트는 기본 문구로 동작하고 관리자 저장은 꺼져요.
